# 🖥️ Windows XP Personal Website

Um projeto pessoal inspirado na interface do Windows XP, desenvolvido com o objetivo de praticar desenvolvimento web e explorar conceitos de interface interativa no navegador.

## 🚀 Sobre o projeto

Este projeto simula um ambiente de desktop semelhante ao Windows XP dentro do navegador. A ideia é criar uma experiência nostálgica e interativa, onde o usuário pode navegar por “janelas” e elementos como se estivesse usando um sistema operacional.

_Embora meu foco principal seja desenvolvimento back-end, desenvolvi este projeto para explorar melhor conceitos de front-end e interfaces interativas._

## 🎯 Objetivos

* Praticar HTML, CSS e JavaScript
* Trabalhar com manipulação de DOM
* Criar interfaces interativas
* Melhorar organização de projeto front-end
* Explorar criatividade em UI/UX

## 🧩 Funcionalidades

* 🪟 Sistema de janelas (abrir/fechar)
* 🖱️ Interação com ícones
* 📁 Simulação de área de trabalho
* 🎨 Interface inspirada no Windows XP
* 🔊 (opcional) sons clássicos do sistema

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript (Vanilla)

## 📂 Estrutura do projeto

```bash
📁 WindowsXP-Personal-Website
 ┣ 📁 images        # Imagens, ícones
 ┣ 📄 style.css     # Estilos
 ┣ 📄 scripts.js    # Scripts
 ┣ 📄 index.html    # Página principal
 ┗ 📄 README.md
```
